# LASH

LASH is a shell for UNIX-like operating systems. It can handle basic commands and can link them with '&&' and '||'. This project is a school project and for learning purposes only.

## Installation

Download the latest version and compile using Makefile. Make sure to check if the dependencies are installed on your system.

### Ubuntu/Debian
```bash
sudo apt install gcc make
```

### Arch Linux
```bash
sudo pacman -S gcc make
```

Compile project using make
```bash
make
```

## Usage

Just run the binary for LASH
```bash
./LASH
```

You can exit LASH using the builtin "exit".

```bash
exit
```
